Circular user or company avatar with initials fallback and optional presence dot.

```jsx
<Avatar src="/u.jpg" status="online" />
<Avatar initials="AK" color="blue" size="sm" />
<Avatar initials="TI" color="gray" size="lg" status="away" />
```

Sizes `xs` 24 / `sm` 32 / `md` 40 / `lg` 48. Status dot: online/away/busy/offline, ringed in the surface color so it reads on any background.
